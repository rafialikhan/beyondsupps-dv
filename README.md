# BeyondSupps mobile-first storefront prototype

Standalone static storefront for GitHub Pages. The product list is a prototype dataset; it is not connected to Shopify and does not process real payments.

## Run locally

Open `index.html`, or serve this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.

## Product photography

Product image URLs were sourced from the first-party Shopify CDN used by [beyondsupps.in](https://beyondsupps.in/). They are currently referenced directly so the preview displays the real catalogue imagery when online.

To vendor the product photos into this repository (recommended before publishing), run:

```bash
./download-assets.sh
```

The script downloads the selected product images into `assets/products/` and rewrites `app.js` to use those local paths. Commit the resulting `assets/products/` files and updated `app.js` to GitHub Pages. If your environment cannot reach the BeyondSupps CDN, run the script from a machine with internet access.

Some catalogue entries without a matching product photo retain the original illustrative SVG fallback. Image mapping and source URLs are recorded in `assets/products/image-sources.json`.

## GitHub Pages

1. Create a GitHub repository, e.g. `beyondsupps-storefront`.
2. Extract this ZIP and copy the folder contents into the repository root.
3. Run `./download-assets.sh` to save product images locally (recommended).
4. Commit and push to the `main` branch.
5. In GitHub, open **Settings → Pages**.
6. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
7. GitHub Pages will publish the site at `https://<your-account>.github.io/<repository>/`.

No build step or framework installation is required.

## Mobile shopping UX

- Two-column product cards sized for thumb use.
- Inline plus/minus quantity controls once an item is in the basket.
- Persistent bottom basket summary with item count and subtotal.
- Bottom-sheet cart drawer on mobile; side drawer on desktop.
- Horizontal category/filter controls and compact product information.
- Product photos are served from the store's own Shopify CDN until downloaded locally.

## Production integration

Before going live, replace the sample product dataset in `app.js` with Shopify Storefront API data, including variant IDs, prices, inventory and image URLs. Connect cart mutations to Shopify Cart API and hand off to Shopify's native checkout. The current checkout is a preview only and never takes payment.

## Brand asset

The supplied official BeyondSupps logo was not present in the available attachments when this prototype was built. Replace the header/footer logo placeholders with the official asset before public release; do not recreate the logo.


## Official logo and themes

The supplied BeyondSupps logo is included at `assets/beyondsupps-logo.png` and used in the header and footer. The original artwork is preserved. In dark mode it is rendered in a light monochrome treatment with a CSS filter; in light mode its original green artwork is shown. The theme toggle in the header switches between dark and light modes and remembers the visitor's preference in local storage.


## GitHub Pages deployment

This is a static site. No build step or server is required. The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml` that deploys the repository root to GitHub Pages on every push to `main`.

If Pages has not yet been enabled for this repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. The workflow will then publish the site.

Product pack illustrations are embedded as inline SVG generated by the app. They are illustrative mockups, not official product packaging. Catalogue and demo prices are not live Shopify data.
